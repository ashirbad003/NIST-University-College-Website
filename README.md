# NIST University College Website

A modern and responsive college website developed for NIST University using pure HTML5 and CSS3. The project demonstrates the practical use of semantic HTML, CSS3 layouts, responsive design, visual styling, forms, image galleries, and interactive hover effects.

## 📌 Project Overview

The NIST University College Website is a single-page responsive website designed to present important information about the university in a clean and professional format.

The website includes academic programs, campus facilities, faculty information, admission registration, contact details, and a campus location map.

## ✨ Features

- Responsive college website design
- NIST University branding and navigation
- Home banner section
- University highlights
- About section with Mission and Vision
- Campus Gallery
- Academic Courses section
- Campus Facilities section
- Faculty information table
- Student Admission Form
- Contact information
- Google Maps integration
- Responsive navigation
- CSS hover animations
- 3D card effects
- Image-based content
- Mobile-friendly layout
